Careers at Techsync

Techsync is growing and we are looking for people who enjoy building websites and want to learn with a friendly and supportive team.

Read the job descriptions below and use the reference number when you submit your application.

Why Join Techsync?

  • Work from home two days a week
  • Free training and online courses
  • Support from experienced team members

Inclusive Employment

Techsync supports reconciliation. We encourage Aboriginal and Torres Strait Islander Peoples to apply for our positions, and we are happy to provide flexible arrangements for cultural and community responsibilities.

Front-End Web Developer

Reference Number: FED01

Job Description

As a Front-End Web Developer, you will build and update websites for our clients using HTML and CSS. The websites must be easy to use and work well on both computers and mobile phones.

Salary and Reporting Line

Salary: $75,000 - $90,000 per year

Reports to: Lead Front-End Developer

Key Responsibilities

  1. Create web pages using HTML5 and CSS3
  2. Make sure all pages follow accessibility guidelines
  3. Test websites on different browsers and devices
  4. Work with the team and update tasks in Jira

Essential Requirements

  • Good knowledge of HTML and CSS
  • Experience using Git and GitHub
  • Basic understanding of web accessibility

Preferable Requirements

  • A degree in Information Technology
  • Some experience with JavaScript

UX/UI Designer

Reference Number: UXD02

Job Description

As a UX/UI Designer, you will design the layout and look of our websites. You will make sure our designs are clear, simple and accessible for all users.

Salary and Reporting Line

Salary: $80,000 - $95,000 per year

Reports to: Design Manager

Key Responsibilities

  1. Create wireframes and designs using Figma
  2. Talk to users to understand what they need
  3. Work with developers to build the designs

Essential Requirements

  • A portfolio of design projects
  • Experience using Figma or a similar tool

Preferable Requirements

  • Basic knowledge of HTML and CSS
  • Experience designing for mobile devices
